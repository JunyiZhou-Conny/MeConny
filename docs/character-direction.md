- 主身份参考是用户提供的微笑、紫色圆领上衣自拍。
- 保留六站、原生滚动、镜头系统、Job Search 场景与静态回退；人物可以重做。

- 躯干、衣领、加载器和动画基础设施可以复用，是否复用取决于新人物的整体效果。

- 已有 Sen 截图仅作为有限的静态风格依据：清楚的鼻颊体积、发束轮廓和柔和光照。

- 最后一版收窄眼形、加宽下颌并减弱尖刺发型；仍是尚未完成三维验证的方向稿。
- 私人自拍和生成图片未写入本仓库。

## 本人辨识度应来自的结构

- 宽椭圆脸、饱满面颊、缓缓收拢的下颌和较宽圆润的下巴，避免尖下巴。
- 保持成年人的头颈肩比例，不靠大头、小下巴和细脖子制造可爱感。
- 笑时眼裂偏长而窄；上眼皮自然遮住一部分深色虹膜，下眼睑随面颊抬起。
- 鼻尖圆润、鼻翼有宽度；自拍的近距离仰拍透视不能直接当作真实三维尺寸。
- 自然露齿笑必须同时改变嘴角、面颊与眼睑，不能只画一条白色牙带。
- 黑发蓬松、略偏分、刘海边缘不齐；用方向明确的发束塑形，避免等粗胶条。
- 紫色圆领上衣是明确的色彩特征；衣服保持简洁，故事贴纸只放衣服上。

## 材质与构图

- 保留胸像、暖米色背景与宽大柔光；眼睛仅有少量高光，皮肤不油亮。
- 目标是有体积的风格化人物；不要把照片磨皮直接当成角色设计完成。
- 脸部起伏和头发大轮廓优先于毛孔、细发丝或布料细纹。
- 先锁定一张清晰的大幅角色图，再建立正面、侧面和四分之三视角的一致性。

## 旧 candidate 的失败教训

- 扁眼白与黑色边线像贴片，眼睑没有自然包住眼球。
- 只压窄眼睛而不调整面颊、眉眼和嘴角，会把微笑变成木讷的侧目。
- 泛化的窄脸、尖下巴和大眼睛削弱了本人辨识度；技术上能眨眼不等于造型合格。
- 耳后投影缝、头发胶条和不连贯的材质不能靠动画或后期光照掩盖。
- 生成图同样可能过度美化成少年脸；高完成度渲染不是身份相似度的证据。

## 进入 3D 前与替换前的质量检查

1. 将设计图与自拍并排，检查眼裂、鼻翼、面颊、下颌、笑容和成年比例。
2. 检查生成图的头发、皮肤是否偏写实，是否仍有明确而统一的雕塑感。
3. 多视图中保持同一人，避免侧面鼻子、耳朵、下巴和头颈连接无依据地变化。
4. 在 Blender 中验证真实眼睑包覆、闭眼轮廓、牙齿和嘴唇关系；不再用扁片补眼睛。
5. 检查耳后、发际、颈侧贴图接缝；正面和四分之三视角都必须成立。
6. 导出真实 GLB 后核对材质、动画、尺寸和 Meshopt 兼容性，再测六站实际镜头。
7. 桌面、手机、滚动、眨眼和静态回退都需实际验证；静帧与构建通过不能代替这些检查。
8. 用户已授权自主取舍和制作；默认人物的替换应以真实资产和页面验证为依据。正式站的合并与发布仍遵循现有审阅要求。
